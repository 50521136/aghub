你的专属接入地址

安卓手机

系统原生私人 DNS · 3 步完成

  1. 打开 设置 → 网络和互联网 → 私人 DNS
  2. 选择 指定主机名
  3. 填入 DoT 主机名，保存
iPhone / iPad

手动填写，或用描述文件一键启用

  1. 打开 设置 → 通用 → VPN 与设备管理 → DNS
  2. 选择 加密 DNS，填入 DoH 地址
  3. 保存后回到「概览」查看战报
电脑 / 路由器

系统或固件支持加密 DNS 时直接填入地址

  • Windows 11设置 → 网络和 Internet → DNS，填入 DoH 地址
  • macOS系统设置 → 网络 → DNS，或安装描述文件
  • 路由器在 DHCP 的 DNS 设置里填入 DoT / DoH
